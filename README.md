# Shubham Kumar — Product Design Portfolio

A world-class, senior-caliber Product Design portfolio website for **Shubham Kumar**, positioning him at the intersection of **Mechanical/Industrial Engineering**, **Predictive Data Analytics**, and **Systems-Level UX Design**.

## ✨ Features
- **Editorial Warm Figma Template Aesthetic**: Styled with Google Fonts **Fraunces** (700 Serif) and **Inter**, with warm peachy-cream canvas (`#FBF1E6`), 24px rounded work cards, and custom vector character illustrations.
- **Heavy Animation Suite**:
  - Interactive 3D Card Tilt with real-time mouse tracking.
  - Floating levitation and staggered badge physics on the hero section.
  - Concentric sonar radar ping waves and ripple pulses on telemetry dots.
  - Smooth scroll-reveal engine with IntersectionObserver.
  - Card hover shimmer beam passes and spring physics.
- **Embedded Interactive Prototypes**:
  - **RetainOS (B2B Enterprise)**: High-density 4-row sortable table with inline sparklines, explainable risk telemetry drawer (3 weighted drivers), and a live What-If action sandbox.
  - **Uber Peak-Demand (B2C Mobile)**: Expandable Zero-Surprise fare pill (`₹380 Total Locked`), 2-tier Fulfillment Confidence toggle, and transparent post-booking radar queue.
  - **Prism-Metric (Design Systems)**: Multi-state & density badge system with built-in 8pt grid Dev Mode token inspection.

## 🚀 How to Host on GitHub Pages (Zero Build Steps)

This project is built with pure, modern HTML5, CSS3, and ES6 JavaScript. There are **zero build dependencies**, zero npm installs, and zero bundlers required.

### Option 1: Using Git (Terminal / CLI)
1. Initialize git in this folder (if not already):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: World-class Product Design Portfolio"
   ```
2. Create a new repository on [GitHub](https://github.com/new) (e.g. `portfolio` or `nothing0g.github.io`).
3. Link your remote and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
4. On GitHub, go to your repository **Settings** → **Pages**:
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, choose `main` / `root (/)` and click **Save**.
5. Your site is live instantly at:
   `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

### Option 2: Drag & Drop via GitHub Web
1. Create a repository on GitHub.
2. Drag and drop all the files (`index.html`, `css/`, `js/`, `assets/`, `.nojekyll`) directly into the repository.
3. Turn on GitHub Pages under **Settings** → **Pages**!
